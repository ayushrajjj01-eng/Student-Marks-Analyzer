📊 Student Marks Analyzer

📌 Introduction

Student Marks Analyzer is a Python-based project developed using Google Colab. It analyzes student academic performance and generates meaningful insights through calculations and data visualization.

🎯 Objectives

* Calculate student-wise average marks.
* Identify the class topper.
* Calculate subject-wise average marks.
* Assign grades automatically.
* Analyze pass and fail results.
* Visualize student performance.

🛠️ Technologies Used

* Python
* Google Colab
* NumPy
* Pandas
* Matplotlib
* GitHub

⭐ Features

1. Student performance analysis.
2. Average marks calculation.
3. Topper identification.
4. Subject-wise analysis.
5. Automatic grade calculation.
6. Pass/Fail analysis.
7. Data visualization using graphs.
8. Final performance report.

📊 Project Dataset

* Number of students: 50
* Class average: 49.97
* Topper: Student 47

▶️ How to Run

1. Open the .ipynb notebook.
2. Open it in Google Colab.
3. Run all cells sequentially.
4. View the results and graphs.

📝 Conclusion

This project demonstrates how Python can be used to analyze student academic performance. It simplifies calculations, grade assignment, and data visualization.
